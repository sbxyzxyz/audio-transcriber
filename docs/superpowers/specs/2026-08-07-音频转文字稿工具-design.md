# 音频/视频转文字稿工具 — 设计文档

日期：2026-08-07
状态：已确认

## 目标

一个本地免费运行的图形界面工具：把视频/音频文件拖进去，点一下，输出带时间戳的文字稿。用途是转自己的视频口播，方便改文案、找素材位置。

## 用户与场景

- 用户：非程序员，短视频自媒体创作者
- 输入：视频（mp4/mov/mkv 等）或音频（mp3/wav/m4a 等），单文件拖入
- 输出：同名 `.txt` 文字稿，带 `[mm:ss]` 时间戳
- 语言：中文为主，支持自动识别
- 隐私：全本地处理，音频不上传，不联网（除首次下载模型）

## 硬件环境（已验证）

- Windows 11，i9-13980HX，RTX 4060 Laptop（CUDA 可用）
- 51GB 内存
- Python 3.12.10 + ffmpeg 已装

## 技术方案

- **识别引擎**：faster-whisper（Whisper 的开源加速版，CTranslate2 后端，支持 CUDA GPU 加速）
- **界面**：Python 自带 tkinter（无需额外装界面库）
- **模型选择**：三档精度
  - 极速：small 模型
  - 标准：medium 模型（推荐，中文准确率高）
  - 高精度：large-v3 模型
- **模型缓存**：首次运行时自动下载到本地 `~/.cache/huggingface`，之后离线可用
- **GPU 加速**：优先 CUDA，失败自动回退 CPU

## 界面流程

1. 打开窗口，中间大拖放区
2. 拖入文件 → 显示文件名
3. 选精度（极速/标准/高精度）→ 默认标准
4. 选语言（中文/自动）→ 默认中文
5. 点【开始转文字】→ 显示进度条和状态文字
6. 完成 → 在源文件同目录生成 `<原名>_文字稿.txt`，弹窗提示完成

## 文字稿格式

```
[00:00] 大家好，欢迎来到我的频道
[00:05] 今天给大家讲讲工地那些事
[00:12] 咱们先看第一个问题
```

- 时间戳按实际秒数，格式 `[mm:ss]`
- 每句一行，句间按识别出的断句切分

## 错误处理

- 非音视频文件 → 弹窗提示不支持
- 引擎运行失败 → 弹窗显示错误，不崩溃
- 转写中可取消

## 排除项（YAGNI）

- 不做 SRT 字幕输出（用户明确只要带时间戳文字稿）
- 不做批量多文件（用户选择先做单文件）
- 不做云同步/多平台
- 不做文字稿编辑（外部工具复制即可）

## 验证方式

用一段真实中文口播音频测试，确认：
1. 输出文字稿存在且内容正确
2. 时间戳格式正确、递增
3. 转写速度可用（标准模型）
